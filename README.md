# Knowledge Board v2

เว็บบอร์ดถาม–ตอบและแบ่งปันความรู้ ภาษาไทย รองรับมือถือ

## เทคโนโลยี
- Node.js + Express 5
- SQLite (better-sqlite3)
- EJS
- Express Session
- Helmet + Rate Limit

## ฟีเจอร์
- สมัครสมาชิก / เข้าสู่ระบบ / ออกจากระบบ
- ตั้งคำถามและตอบคำถาม
- โหวตคำตอบ + ระบบคะแนนชื่อเสียง
- ยอมรับคำตอบที่ถูกต้อง
- ค้นหา + หมวดหมู่ + แท็ก
- บันทึกคำถามไว้ดูภายหลัง
- แจ้งเตือนเมื่อมีคนตอบ/โหวต/ยอมรับคำตอบ
- โปรไฟล์และตั้งค่าบัญชี
- รูปประกอบผ่าน URL
- Admin Dashboard / ลบกระทู้ / ลบสมาชิก
- Responsive สำหรับมือถือ
- SQLite สร้างฐานข้อมูลอัตโนมัติ

## ติดตั้งบน Windows
1. ติดตั้ง Node.js รุ่น LTS จากเว็บไซต์ทางการของ Node.js
2. แตก ZIP
3. เปิด PowerShell ในโฟลเดอร์นี้
4. รัน:

```bash
npm install
npm start
```

5. เปิด `http://localhost:3000`

## ตั้งค่า production
กำหนด environment variable `SESSION_SECRET` เป็นค่าสุ่มยาว ๆ และตั้ง `NODE_ENV=production`

## หมายเหตุ
ฟังก์ชันรูปภาพในเวอร์ชันนี้รับเป็น URL เพื่อให้โปรเจกต์ติดตั้งง่าย หากต้องการอัปโหลดไฟล์จริง สามารถเพิ่ม storage เช่น local uploads หรือ object storage ในขั้นต่อไปได้
